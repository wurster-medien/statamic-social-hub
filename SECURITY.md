# Sicherheitslücken melden

Bitte Sicherheitslücken **nicht** als öffentliches Issue oder Pull Request melden.

Stattdessen eine der beiden Möglichkeiten nutzen:

1. Auf GitHub unter **Security → Report a vulnerability** (private Meldung, nur für uns sichtbar).
2. Per E-Mail an dev@wurster-medien.de.

Hilfreich sind: betroffene Version, Schritte zum Nachstellen und die möglichen Auswirkungen.

Wir bestätigen den Eingang in der Regel innerhalb von drei Werktagen, beheben die Lücke in der aktuellen Version und veröffentlichen danach ein Security Advisory. Wer die Lücke gemeldet hat, wird dort auf Wunsch genannt.

## Unterstützte Versionen

Sicherheitsupdates gibt es für die jeweils neueste Minor-Version.
